# GOBSHITE! — The Runaway Railway (Prototype 0.8)

Mobile-first browser endless runner.

## Run
- Node.js 20+
- `npm install` (no external dependencies required)
- `npm start`

## Controls
- Swipe left/right: change lane
- Swipe up: jump
- Swipe down: duck
- Keyboard: arrows or WASD; Escape pauses
