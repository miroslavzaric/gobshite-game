# GOBSHITE! — Prototype 0.2

Updated playable prototype with:
- A custom pixel-art-style Irish leprechaun drawn in the game (no emoji hero).
- Perspective railway with two steel rails, wooden sleepers, ballast and rail fastenings.
- Obstacles positioned and scaled against the track perspective, with collision timing aligned to their approach.
- Swipe and keyboard controls, score/best score, pause and sound toggle.

## Run
Requires Node.js 20+. Run `npm start`, then open `http://localhost:3000`.

## Railway
Deploy from GitHub; Railway runs `npm start` and supplies `PORT`.
